# @codee/lang-cpp

C++ language support for Codee.

## Features
- Runtime metadata and modern C++ idioms.
- AST hooks with tree-sitter-cpp or clangd.
- Templates for STL containers, smart pointers, and concurrency.
- Modern C++20 templates for ranges, concepts, and coroutines.
- LSP integration via `clangd`.

## Templates
- stdlib: containers, smart pointers, concurrency
- modern-cpp: ranges, concepts, coroutines
- boost/qt/embedded: starter snippets

## Usage
This package is consumed by the Codee language registry and does not expose a CLI.
