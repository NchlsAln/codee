# @codee/lang-java

Java language support for Codee.

## Features
- JVM runtime metadata and ecosystem context (Maven, Gradle, Spring).
- Tree-sitter analysis hooks and Java-specific type hints.
- Templates for standard library collections/IO and Spring Boot layers.
- LSP integration via `jdtls`.

## Templates
- stdlib: collections, IO
- spring: controllers, services, repositories
- jpa: entity example
- android: activity skeleton

## Usage
This package is consumed by the Codee language registry and does not expose a CLI.
