# FAQ

## Is Codee local-first?
Yes. Codee runs locally by default and does not send code externally unless you enable cloud features.

## Does Codee collect telemetry?
Only if you opt in. Telemetry is disabled by default.

## Does Codee work offline?
Yes. Enable Offline Mode to block non-local network access.

## Can I use my own model?
Yes. Provide a local model path or use an Ollama model.

## How do I report issues?
Use **Codee: Send Feedback** or open a GitHub issue from the repository.
