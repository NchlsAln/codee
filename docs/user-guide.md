# User Guide

## Getting Started
1. Install Codee (desktop or VS Code extension).
2. Open a project folder.
3. Complete the onboarding wizard to configure local models and indexing.

## Core Workflows
- Chat: ask Codee to explain, refactor, or draft code.
- Context: attach files, symbols, or selections for better responses.
- Tests: generate unit tests from selected code.

## Local-First Defaults
- Codee runs locally by default.
- Cloud fallback is off unless explicitly enabled.
- Offline mode blocks non-local network access.

## Feedback
Use **Codee: Send Feedback** to open a GitHub issue template, or join Discussions for Q&A.

## Privacy & Telemetry
- Telemetry is opt-in and off by default.
- Crash reporting is opt-in and off by default.
- See PRIVACY.md for details.
