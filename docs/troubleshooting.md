# Troubleshooting

## Codee does not respond
- Check that indexing is complete and the engine status is ready.
- Restart the engine using **Codee: Restart Engine**.
- Open **Codee: Open Engine Logs** for details.

## Model download fails
- Ensure Ollama is installed and running.
- Run **Codee: Download Model** and verify the model name.

## Offline mode blocks cloud endpoints
- Disable Offline Mode or keep cloud fallback disabled.

## UI not loading
- Reload the VS Code window.
- Clear local data if the webview is stuck.

## Where are logs stored?
- Use **Codee: Open Engine Logs** in VS Code.
- Export a debug log via **Codee: Export Debug Log**.
