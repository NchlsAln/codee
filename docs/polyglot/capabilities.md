# Polyglot Capabilities

Codee's polyglot system focuses on idiomatic translations across Python, TypeScript, Rust, Go, Java, C++, Kotlin, Scala, C#, Swift, and Dart. The engine detects high-signal patterns and produces target-language equivalents rather than literal line-by-line conversions.
