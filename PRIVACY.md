# Privacy Policy (Beta)

Last updated: 2026-02-15

## Local-First by Default
Codee processes code locally by default. Your source code, embeddings, and chat history stay on your device unless you explicitly enable cloud features.

## Telemetry (Opt-In)
- Disabled by default.
- When enabled, Codee sends anonymous usage metrics (events only, no code content).
- PostHog is used for analytics in self-hosted mode.

## Crash Reporting (Opt-In)
- Disabled by default.
- When enabled, Codee sends crash reports to a self-hosted Sentry instance.
- Crash reports may include stack traces and OS/app metadata.

## Data Retention
You control local retention using `codee.privacy.dataRetentionDays`.
